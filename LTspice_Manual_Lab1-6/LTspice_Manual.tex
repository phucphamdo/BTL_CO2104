\section*{Preface}
This manual replaces the former PSpice for TI laboratories with LTspice, a free circuit simulator from Analog Devices. It contains six laboratories; each laboratory has ten main exercises and a set of advanced exercises.

\textbf{What you need.} The offline LTspice installation provided for the course (including the component libraries). All schematics in this manual open and run on that installation without downloading anything else.

\textbf{How to work.}
\begin{enumerate}
  \item Read the introduction and the LTspice guide of the laboratory.
  \item For each exercise, complete the \emph{Theory calculation} by hand: the calculation space is intentionally blank, and the reference solutions are given only to the instructor.
  \item Build the circuit in LTspice, run the analysis indicated in the \emph{LTspice simulation} part and save the schematic as \file{LabN/ExNN.asc} (advanced exercises: \file{LabN/AdvNN.asc}).
  \item Fill in the \emph{Comparison} table with your theoretical and simulated values and comment on any difference.
\end{enumerate}

\textbf{Conventions.} Component names follow the figures (R1, V1, \dots). Values use SPICE prefixes (\texttt{k}, \texttt{Meg}, \texttt{m}, \texttt{u}); remember that \texttt{M} also means milli in SPICE. Voltage and current signs follow the reference directions shown in each figure; LTspice reports the current of a voltage source as positive when it enters the positive terminal.
